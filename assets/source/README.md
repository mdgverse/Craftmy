# Modelo de referência

**BodyChan - BodyKun | Posable Drawing Figures**, por vinchau.
Fonte: https://blendswap.com/blend/23521
Licença indicada na página: CC0.

`bodychan-bodykun.blend` é o original fornecido pelo usuário. `bodykun-export.zip` é a conversão enviada pelo usuário; o GLB incluído contém o modelo BodyKun e uma armadura, mas não o BodyChan. O GLB usado pelo site está em `public/models/bodykun.glb`.

O formato glTF não executa os controles e restrições Rigify do Blender. A integração experimental manipula diretamente os ossos de deformação e não reproduz o rig completo nem adaptações de biotipo ou cabelo.
